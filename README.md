## 🎮 Особенности

* **Три режима игры:**
  * **1 на 1** — тактическая дуэль против умного ИИ.
  * **Втроём** — классический режим «каждый сам за себя».
  * **2 на 2 (Пара на пару)** — командная битва с напарником (друг напротив друга) с совместным подсчётом очков команды.
* **Сетевой мультиплеер (Online Lobby):**
  * Создание приватных комнат с 4-значным кодом и ссылкой-приглашением.
  * Выбор любого свободного кресла за круглым столом.
  * Возможность посадить ботов на любые пустые места (**«+ Бот»**).
  * Случайная жеребьёвка команд («Случайные пары») и кнопка готовности.
  * Внутриигровой быстрый чат с короткими фразами («Привет!», «Хороший ход!», «Рыба!» и др.).
* **Атмосферный визуал:**
  * Зелёное сукно стола с процедурной текстурой.
  * Объёмные костяшки цвета слоновой кости с углублениями для точек и латунной осью (spinner) по центру.
  * Всплывающие золотистые облачка над сыгранной костяшкой с суммой выигранных очков (`+1 очко`, `+2 очка`, `+5 очков`).
  * Полная адаптивность: комфортно играть как с широкоформатных мониторов ПК, так и со смартфонов и планшетов.
* **Честный и сильный ИИ:**
  * Боты используют эвристический анализ очков, блокировку мастей соперников, прикрытие напарника в командной игре и расчёт оставшихся камней на базаре.

## 📜 Правила («Пятёрочка» / All Fives)

1. **Цель:** Первыми в команде (или соло) набрать **71 очко**.
2. **Результативные ходы:** Очки начисляются сразу во время хода, если сумма всех открытых концов цепочки кратна **5**:
   * Сумма 5 → **1 очко**
   * Сумма 10 → **2 очка**
   * Сумма 15 → **3 очка**
   * Сумма 20 → **4 очка**
   * Сумма 25 → **5 очков**
3. **Первый дубль («Дом»):**
   * Первый выставленный на стол дубль открывает крестообразное развитие: к нему можно пристыковывать костяшки с четырёх сторон.
4. **Окончание раунда:**
   * Раунд заканчивается, когда один из игроков выставил все костяшки («вышел») или случилась «рыба» (никто не может сделать ход, базар пуст).
   * Оставшиеся на руках очки суммируются, округляются по правилам игры и начисляются победителю раунда.

## 🚀 Быстрый запуск локально

Проект написан на легковесном стеке без тяжелых фреймворков и баз данных (чистый HTML5 / CSS3 / ES-модули на клиенте и Node.js + WebSocket на сервере).

### Требования
* [Node.js](https://nodejs.org/) версии 18 или выше.

### Запуск
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/qwertynovo2026-dotcom/domino-game.git
   cd domino-game/domino
   ```
2. Установите зависимость (`ws`):
   ```bash
   npm install
   ```
3. Запустите сервер:
   ```bash
   npm start
   ```
4. Откройте в браузере: `http://localhost:3000`  
   *(Или просто дважды кликните по `start-local.bat` в корне проекта на Windows).*
